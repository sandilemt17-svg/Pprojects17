EventEaseSystem
> A cloud-based event management platform for organisers and attendees.

Overview
> EventEaseSystem helps users create, manage, and book events with real-time seat availability. Built as a student cloud project to learn serverless architecture
and infrastructure as code.

Database: Local DBS within MS Visual Studio.
Storage: Azurite for event images.

Features
- Create, edit, and delete events and venues.
- Event search & filters (planned).
- Error message when an attempt to delete a booked venue is prompted.

How To Run
> Clone the repo
git clone https://github.com/sandilemt17-svg/Pprojects17/EventEaseSystem.git

> Open EventEaseSystem.csproj or EventEaseSystem.slnx in Visual Studio 2022
> Press F5 to build and run

CyberSecurityBot
> A C# application bot built to educate users.

Overview
> CyberSecurityBot is a bot programmed to educate users on cybersecurity and provide tips to protect their devices and personal data.

Features
- Voice GreetingPlays greeting.wav automatically on startupASCII.
- Logo displayed as the first chat message.
- Check-in5 cybersecurity questions to assess the user's awareness.
- Keyword Recognition: Detects 9+ cybersecurity topics from user input.
- Random Responses: Multiple responses per topic, randomly selected via delegate.
- Conversation Flow: "Tell me more" / "Give me another tip" continues the last topic.
- Quick Topic Chips: Sidebar buttons to instantly query any cybersecurity topic.
- CommandType "exit", "bye", or "quit" to end the session.

Cybersecurity Topics Supported:
- Password Safety
- Phishing & Scams
- Safe Browsing
- Two-Factor Authentication (2FA)
- Malware & Ransomware
- Data Privacy & VPNs
- Social Engineering
- Identity Theft

How to Run
> Clone the repo:
git clone https://github.com/sandilemt17-svg/Pprojects17/prog6221-g3-2026-part1-ST10472078.git

> Open CyberSecBotWPF.csproj or CyberSecurityBot.slnx in Visual Studio 2022
> Ensure greeting.wav is inside the Assets/ folder
> Press F5 to build and run
